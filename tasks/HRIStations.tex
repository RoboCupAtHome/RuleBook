\section{Human Robot Interaction Challenge}
\label{test:human-robot-interaction-challenge}

\subsection*{Description}
The robot encounters and solves a set of Human-Robot Interaction (HRI) scenarios distributed throughout the \Arena{}. Each scenario presents a different situation requiring the robot to perceive, recognize, and interact with people.\\
    
\textbf{Main goal:}
    Complete as many HRI scenarios as possible.
% \vspace{-5pt}


\subsection*{Focus}
\emph{\SysI{}}, \emph{\HRI{}}, \emph{\PerDet{}}, \emph{\PerRec{}}
% human detection and recognition, safe navigation and human-robot interaction with unknown people.

\subsection*{Setup}
\begin{itemize}
	\item \textbf{Locations:}
		\begin{itemize}
			\item \textbf{Start location:} The robot waits outside the arena and enters when the door is opened.
			\item \textbf{Scenario locations:} The scenarios are distributed across different rooms of the \Arena{}.
		\end{itemize}
\end{itemize}


\subsection*{Scenarios}
Several scenarios will be set up at different locations throughout the \Arena{}. Each scenario represents an independent HRI task and is evaluated separately.

The robot may choose the order in which to approach and solve the scenarios. The locations of the scenarios are announced in advance.

\subsection*{Additional rules and remarks}
\begin{enumerate}[nosep]
	\item Each scenario can be attempted independently.
	\item The robot may choose the order in which to visit the scenarios.
\end{enumerate}

	\item Assign the volunteers to the different rooms and scenarios.
\end{itemize}

During setup day:
\begin{itemize}
	\item Announce the rooms assigned to the scenarios.
\end{itemize}

At least two hours before test:
\begin{itemize}
	\item Recruit and instruct volunteers required for the scenarios.
\end{itemize}
